# Healthcare Data Analysis – Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a healthcare dataset using Python. It explores patient age, gender, medical conditions, admission types, and billing amounts through data analysis and visualization.

## Objectives
- Understand the healthcare dataset.
- Explore patient age and gender distribution.
- Analyze different medical conditions.
- Compare admission types across medical conditions.
- Understand the distribution of patient billing amounts.
- Represent data using charts and graphs.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Dataset
The project uses a preprocessed healthcare dataset named `healthcare_preprocessed (1).csv`.

The analysis focuses on the following columns:
- `Age` – Patient age
- `Gender` – Patient gender
- `Medical_Condition` – Patient medical condition
- `Admission_Type` – Type of hospital admission
- `Billing_Amount` – Patient billing amount

## Tasks Performed

### 1. Data Exploration
- Displayed the first few rows of the dataset.
- Checked the number of rows and columns.
- Retrieved column names.
- Examined the dataset structure and data types.

### 2. Patient Age Analysis
- Created a histogram to understand the distribution of patient ages.
- Compared age distributions by gender.

### 3. Gender Analysis
- Counted patients by gender.
- Visualized the gender distribution using a bar chart.

### 4. Medical Condition Analysis
- Counted patients across medical conditions.
- Compared medical conditions by gender using a count plot.

### 5. Admission Type Analysis
- Visualized the distribution of admission types.
- Created a cross-tabulation of medical conditions and admission types.
- Used a stacked bar chart to compare admission types across medical conditions.

### 6. Billing Amount Analysis
- Created a histogram to understand the distribution of patient billing amounts.
- Used a density curve to observe the distribution pattern.

## How to Run the Project
1. Download the `EDA_6.ipynb` notebook.
2. Keep the healthcare CSV dataset available.
3. Open the notebook in Jupyter Notebook or Google Colab.
4. Upload the CSV file to the environment.
5. Update the dataset file path if necessary.
6. Run all cells in order.

## Conclusion
This project demonstrates how Exploratory Data Analysis can be used to understand healthcare data. Charts and statistical summaries help explore patient demographics, medical conditions, hospital admission types, and billing amount patterns.
